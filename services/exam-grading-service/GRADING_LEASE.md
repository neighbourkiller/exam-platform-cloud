# 主观题阅卷认领

认领粒度为 `grading_task.answer_id`，即某次提交中某位学生的一道题。按题目批量评分和按学生评分使用同一租约规则。

- 点击“认领批阅”后，通过 MySQL 条件 UPDATE 抢占 5 分钟租约。有效租约不能被其他老师或同一老师的另一窗口覆盖。
- 租约时间以数据库时间为准；到期后可直接再次认领，不依赖清理任务。支持手动续期和释放。
- 大厅仍展示全部待批项（包括正在被认领的项）；认领结果以服务端为准。前端在认领成功后展示答案并允许评分，冲突时提示刷新或重试。
- 评分必须携带租约令牌；服务端原子校验老师、令牌、有效期、待批状态及分数范围。旧窗口、过期令牌和重复提交不能再次写入评分。
- 批量评分采用整批事务：任一评分项失效则整批回滚。同一份试卷的评分事务通过提交记录行锁串行汇总，批量跨试卷时按提交 ID 排序加锁。
- 切换页面时前端尽力释放持有的租约；关闭浏览器或网络中断时由 5 分钟超时兜底。不自动续期，避免闲置页面长期占用。

## HTTP 接口

统一前缀 `/api/v1/grading`，沿用 TEACHER / ADMIN 授权。

| 操作 | POST 路径 | 请求体 |
| --- | --- | --- |
| 认领 | `/answers/{answerId}/claim` | 无 |
| 续期 | `/answers/{answerId}/renew` | `{ "token": "当前租约令牌" }` |
| 释放 | `/answers/{answerId}/release` | `{ "token": "当前租约令牌" }` |

认领和续期返回 `token` 与 `expiresInSeconds`。按学生评分的每个 `scores` 项增加必填 `leaseToken`；按题目评分增加必填 `leaseTokens` 映射，键为答案 ID。缺少令牌的旧客户端无法评分。

## 发布与回退

1. 暂停阅卷入口并等待在途评分完成，备份 grading Schema。
2. 停止旧版阅卷实例，再启动新版服务，由 Flyway 执行 `V7__grading_task_lease.sql`。迁移只增加可空列，不修改历史成绩。
3. 同步发布前端，验证两个老师竞争同一答案、过期接管以及两种评分模式后恢复入口。不要混跑新旧阅卷实例，旧版评分逻辑不检查租约。
4. 回退时先暂停入口并排空请求，再成套回退前后端；新增可空列可保留。旧版不具备并发保护，回退后不能继续按本功能的保障开放多人阅卷。

本功能不变更其他服务 Schema、Feign 契约、事件载荷或消息拓扑；成绩完成事件仍走已有事务内 Outbox。
