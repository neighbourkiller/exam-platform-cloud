# 主观题阅卷租约运维手册

本文仅描述主观题阅卷租约的发布、验证和回退操作。业务行为与接口说明见[主观题阅卷认领](../../documents/技术文档/业务流程/主观题阅卷认领.md)。

## 发布前

1. 暂停阅卷入口并等待在途评分完成。
2. 备份 Grading 服务所属 Schema。
3. 确认待发布版本包含 `V7__grading_task_lease.sql`，并确认前后端版本成套发布。

## 发布

1. 停止旧版阅卷实例，避免新旧评分逻辑混跑。
2. 启动新版 Grading 服务，由 Flyway 执行 `V7__grading_task_lease.sql`。该迁移只增加可空列，不修改历史成绩。
3. 发布新版前端。
4. 验证两个老师竞争同一答案、租约过期接管、按学生评分和按题目评分，再恢复阅卷入口。

## 回退

1. 暂停阅卷入口并排空在途请求。
2. 成套回退前端和 Grading 服务，不能混跑新旧实例。
3. 新增的可空租约列可以保留，不需要回滚 Schema。
4. 旧版不具备租约并发保护；回退后不能继续按租约功能的保障开放多人阅卷。

本功能不改变其他服务 Schema、Feign 契约、事件载荷或消息拓扑；成绩完成事件仍通过现有事务内 Outbox 发布。
